## Deutsch

Der **Underground Simulator** ist eine hochperformante, CLI-basierte Zugsimulation, die speziell für die realitätsgetreue Koordination und Automatisierung von Schienennetzen entwickelt wurde. Angetrieben von einer maßgeschneiderten Multi-Thread-Architektur bietet das System eine stabile Plattform für den Mehrspielermodus und komplexe Automatisierungsszenarien.

### 🌟 Features

* **Multi-Threaded Server-Architektur** – Native Server-Client-Kommunikation basierend auf dem Netty-Framework für minimale Latenzen im Multiplayer.
* **TrackScript Integration** – Steuerung von Signalen, Weichen und Fahrstraßen über eine integrierte, performante Skriptsprache inklusive Debugger.
* **Interaktiver Linien-Editor** – Schnittstelle zur webbasierten Erstellung und Visualisierung von Streckennetzen mittels Leaflet und OpenRailwayMap.
* **Echtzeit-Simulation** – Präzise Berechnung von Zugbewegungen, Fahrzeiten und Signalabhängigkeiten direkt auf dem Server.

### 🛠️ Technologie-Stack

* **Core:** Java (Server/Engine), Python (TrackScript Runtime/Debugger)
* **Netzwerk:** Netty Framework
* **Build-Management:** Maven
* **Plattformen:** Linux (Optimiert für Ubuntu/Debian), CLI

## <a id="en">English</a>

**Underground Simulator** is a high-performance, CLI-based train simulation designed for realistic transit network coordination and automation. Powered by a custom multi-threaded architecture, it provides a rock-solid platform for multiplayer operations and complex transit automation.

### 🌟 Key Features

* **Multi-Threaded Server Architecture** – Native server-client communication powered by the Netty framework for ultra-low latency multiplayer.
* **TrackScript Integration** – Advanced control of signaling, switches, and routing via a dedicated, lightweight scripting language with a built-in debugger.
* **Interactive Line Editor** – Seamless integration with a map-based editor utilizing Leaflet and OpenRailwayMap for precise network design.
* **Real-Time Simulation** – Accurate physics, timing, and signaling dependencies simulated directly on the server backend.

### 🛠️ Tech Stack

* **Core:** Java (Server/Engine), Python (TrackScript Runtime/Debugger)
* **Networking:** Netty Framework
* **Build Automation:** Maven
* **Environments:** Linux (Ubuntu/Debian optimized), CLI

## <a id="fr">Français</a>

**Underground Simulator** est une simulation de train en ligne de commande (CLI) à haute performance, conçue pour la coordination et l'automatisation réalistes des réseaux de transport. Propulsé par une architecture multi-thread sur mesure, il offre une plateforme robuste pour le jeu en multijoueur et l'automatisation des lignes.

### 🌟 Fonctionnalités Principales

* **Architecture Serveur Multi-Thread** – Communication serveur-client native basée sur le framework Netty pour un multijoueur à très faible latence.
* **Intégration TrackScript** – Contrôle avancé de la signalisation, des aiguillages et des itinéraires via un langage de script dédié avec débogueur intégré.
* **Éditeur de Lignes Interactif** – Intégration fluide avec un éditeur cartographique utilisant Leaflet et OpenRailwayMap pour la conception de réseaux.
* **Simulation en Temps Réel** – Calculs précis des mouvements de trains, des horaires et des dépendances de signalisation directement sur le serveur.
